# piano-learning-tracker

Web aplikacija za praćenje napretka učenika klavira i organizaciju nastavnog procesa, razvijena u ASP.NET MVC tehnologiji.

## Opis projekta

Cilj projekta je omogućiti jednostavnije praćenje napretka učenika kroz organizaciju sati, evidenciju aktivnosti i pregled razvoja vještina učenika.

Projekt je razvijen kao dio fakultetskog projekta.

---

## Tehnologije

- ASP.NET MVC
- .NET
- Entity Framework
- LINQ
- MySQL
- HTML
- CSS
- jQuery

---

## Funkcionalnosti

- upravljanje podacima o učenicima
- CRUD operacije
- povezivanje s bazom podataka
- pregled i organizacija podataka

---

## Razvoj projekta

Tijekom razvoja koriste se AI alati kao podrška pri:
- istraživanju rješenja
- optimizaciji development workflowa
- UX/UI iteracijama
- debugiranju i implementaciji funkcionalnosti

Korišteni alati:
- Claude
- GitHub Copilot
- ChatGPT

## Status projekta

Projekt je trenutno u fazi razvoja.
